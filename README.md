# PHW-V01 packaging, 3D viewer (Chinese)

The folding and assembly viewer for the PHW-V01 packaging (box, tray, bank box PHW-B01), in Chinese, for the packaging factory: https://dylanc0720-cmyk.github.io/phw-packaging/

`index.html` is generated by `humanbird_cottage/01_desk/design/packaging_box/r3/scripts/make_factory_zh.py`. Do not edit it by hand: re-run that script, then commit and push here.

`lib/` holds three.js r128 and its OrbitControls (MIT, Copyright 2010-2021 Three.js Authors), served from here so the page needs no CDN.
